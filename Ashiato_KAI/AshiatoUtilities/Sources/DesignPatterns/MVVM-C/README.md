# ArchitectureModule

Follow the design pattern architectures in an easy and right way.


## <a id="overview"></a>Overview

This library intends to provide a collection of classes and protocols with a target to do abstractions over the design pattern architectures making simple, standardized, and correct implementation.  

At the moment, this library provides architecture abstraction for the following design patterns:

- MVVM-C;
